# Desenvolvimento deste pacote

Preserve a licença existente e a proveniência. O manual histórico é referência, não bootstrap.
Para alterar a metodologia, comece em skills/pvc/SKILL.md e leia somente a operação pertinente.
Para alterar o CLI, leia docs/ESTADO.md. Execute python -m unittest discover -s tests -v e python scripts/pvc.py check-package.
Uma checagem estrutural não comprova comportamento de agentes nem operação do produto.
